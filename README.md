# SD Majesta — Elevating Urban Luxury

An ultra-luxury architectural real estate web application crafted with a matte black and champagne gold aesthetic, editorial typography, and high-performance React + Vite architecture.

---

## 🏛️ Project Overview

**SD Majesta** is a premier luxury real estate brand delivering high-end residential monuments. This repository hosts the official web experience showcasing flagship developments like **Horizon Sky Residences & Penthouses**, comprehensive lifestyle amenities, interactive financial investment estimators, and a personalized 1-on-1 WhatsApp concierge desk.

---

## ✨ Key Features

- **Cinematic Visual Experience**:
  - Full-screen architectural hero showcase with fluid reveal animations.
  - Matte black (`#070707`) & champagne gold design system with editorial typography (*Playfair Display* & *Poppins*).
  - High-resolution architectural renders of exterior facades, double-height grand lobbies, infinity sky pools, and penthouses.

- **Dedicated Flagship Showcase — Horizon**:
  - Deep-dive project page (`/projects/horizon`) featuring 3 BHK Royal Suites, 4 BHK Imperial Residences, and 5 BHK Sky Duplex Penthouses.
  - Interactive floor plan tab switcher with specifications, square footage, and inclusions.
  - Full-screen high-definition lightbox visual gallery.

- **Smart WhatsApp Concierge Desk**:
  - Multi-intent selector:
    - 📅 *Schedule Private Site Visit*
    - 🏢 *Inquire About Horizon Residences*
    - 🛎️ *Concierge Desk Direct Assistance*
    - 📜 *Request E-Brochure & Pricing Sheet*
  - Instant auto-generated customized message preview and one-tap encrypted launch to WhatsApp.

- **Interactive Financial Investment & EMI Estimator**:
  - Dynamic sliders for property valuation, down payment percentage, loan tenure, and interest rates.
  - Live calculation of monthly EMI, total interest, and principal breakdown.

- **Strategic Connectivity & Prime Address Navigator**:
  - Interactive distance & travel time matrix for airports, championship golf courses, luxury retail, and business hubs.
  - Direct Google Maps navigation link.

- **Social Proof & Accreditations**:
  - Endorsements from industrial leaders and international architects ("Voices of Distinction").
  - Credentials bar highlighting *IGBC Gold Certification*, *RERA Approval*, and *Architectural Eminence*.

- **Instant VIP Dossier Download**:
  - Modal form for instantaneous digital brochure dispatch and text dossier generation.

## 🛠️ Technology Stack

- **Core**: React 19, JavaScript (ESNext)
- **Routing**: React Router DOM v7
- **Styling**: Pure Modern CSS with custom design tokens (CSS Variables, Flexbox, Grid, Glassmorphism, Micro-animations)
- **Build Tool**: Vite 8
- **Typography**: Google Fonts (*Playfair Display*, *Poppins*)

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Nikhil0-1/SD-Majesta.git
   cd SD-Majesta
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
